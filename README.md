# Household Receipts (phone app)

Live at **https://proespaul.github.io/receipts/** (GitHub Pages, this repo's `main` branch).

Snap a receipt and every line item lands in the household Google Sheet, matched against the bank and tracked against the budget.
The backend is the "Household Receipts" Apps Script project; its code is in `backend/`. See `backend/SETUP.md`.

It used to live under the Feed Calculator at `/feedcalc/receipts/`; that address now redirects here.
